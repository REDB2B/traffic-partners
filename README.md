# TRAFFIC NEXUS — Media Buying & Traffic Landing Page

Стильный, адаптивный и интерактивный лендинг для поиска партнёров, команд и рекламодателей в сфере медиабаинга и арбитража трафика.

Выполнен в гибридном стиле:
* **Dark Tech / Cyberpunk:** живая консоль потока событий, неоновые акценты (Mint / Cyan), темная нео-тема, светящиеся элементы.
* **Fintech Minimal:** строгие метрики, структурированные карточки условий (выплаты, трекинг, капы), интерактивный конфигуратор/матчер связок.

## 🚀 Как запустить на GitHub Pages (бесплатно за 2 минуты)

1. Создайте новый репозиторий на GitHub (например, `traffic-partners`).
2. Загрузите в корень репозитория файлы:
   * `index.html`
   * папку `css/` с файлом `style.css`
   * папку `js/` с файлом `main.js`
3. В настройках репозитория:
   * Перейдите в **Settings** -> **Pages** (боковое меню слева).
   * В разделе **Build and deployment** выберите Source: `Deploy from a branch`.
   * В поле ветки выберите `main` (или `master`) и папку `/ (root)`.
   * Нажмите **Save**.
4. Через 30–60 секунд ваш сайт будет доступен по ссылке `https://<ваш_логин>.github.io/<имя_репозитория>/`.

## ⚙️ Настройка контактов

В файле `index.html` замените:
1. `https://t.me/your_telegram_username` на вашу реальную ссылку Telegram.
2. В кнопке `data-copy="your_telegram_username"` и в футере укажите ваш юзернейм без символа `@`.
