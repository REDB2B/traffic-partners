# GOOGLE CLUSTER — Performance Landing Page

Высококонверсионный промо-лендинг для закрытой performance-команды по **Google Ads**. 

### Визуальный стиль и концепция (в точности по референсам):
* **Цветовая палитра:** Глубокий глянцевый чёрный (`#070709`), неоновый ультра-маджента / hot pink (`#ff007a`), чистый белый.
* **Позиционирование:** Закрытый формат для серьёзных партнёров. Никакой «воды» и продажи курсов. Фокус на 100% готовую инфраструктуру в Google Ads (Google Farm Factory, агентские кабинеты, антишторм-сетапы, Keitaro TDS, Telegram-прокладки и боты под ключ).
* **Конверсионная воронка:** Прогрев клиента с рекламы → Интерактивная проверка оффера и ГЕО → Переход в Telegram-бота.

---

## 🚀 Как запустить на GitHub Pages (за 1 минуту)

1. Распакуйте архив в корень вашего GitHub-репозитория:
   * `index.html`
   * папка `css/style.css`
   * папка `js/main.js`
2. В `index.html` замените `https://t.me/your_telegram_bot` и `@your_telegram_bot` на ссылку и юзернейм вашего реального бота.
3. В репозитории откройте **Settings** → **Pages** → выберите ветку `main` (папка `/root`) → нажмите **Save**.
4. Сайт мгновенно доступен по вашей ссылке на GitHub Pages.
